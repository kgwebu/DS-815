## Working with the notebooks

1. Save a personal working copy before adding your responses.
2. Read the notebook's setup and the instructions for each activity.
3. All supplied code cells contain comments only. Write and run your own solution underneath them; add Markdown cells for written explanations.
4. Complete activities in order and check your completed notebook from a fresh kernel before submitting.
